Demo HTML5 Web Storage

Local Storage và Session Storage. Mở DevTools (F12) → Application → Storage để xem dữ liệu.

1. Giao diện sáng / tối

localStorage · khóa: theme

Tải lại trang hoặc đóng trình duyệt, lựa chọn vẫn được giữ.

2. Ghi chú nhanh

localStorage · khóa: note · đồng bộ giữa các tab

3. Bộ đếm lượt xem

sessionStorage: views · localStorage: visits

Lượt xem trong phiên (tab) này: 0

Tổng số lần mở trang (mọi tab): 0

Mở tab mới: số phiên bắt đầu lại từ 1, tổng vẫn tăng tiếp.

4. Lưu nháp biểu mẫu

sessionStorage · khóa: draft_name, draft_msg

Gõ dở rồi bấm F5, nội dung còn nguyên. Đóng tab thì mất.
